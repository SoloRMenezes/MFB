# MFB website preview

Temporary bilingual review website. Content is subject to company validation.

Preview: https://solormenezes.github.io/MFB/

The enquiry form prepares a local summary only; email delivery is not configured.
Photography is illustrative, not MFB equipment or an Angolan location.

Edit bilingual content in `build.py`, then run `python3 build.py`.
Serve under `/MFB/`. No external dependencies are required.
